# ------------------------------------------------------------------------------
# 1. API TRA CỨU TRỰC TIẾP THEO {IP} (TRẢ VỀ JSON - KHÔNG CẦN API KEY)
# ------------------------------------------------------------------------------

ip-api.com
- API: http://ip-api.com/json/{IP}
- Free Plan: 45 requests/phút (Miễn phí 100%, không cần đăng ký tài khoản hay API key)
- Dữ liệu: Geolocation (Country, Region, City, Lat/Lon, Timezone), ASN, ISP, Org

ipwho.is
- API: https://ipwho.is/{IP}
- Free Plan: 10,000 requests/tháng (Miễn phí, không cần API key)
- Dữ liệu: Geolocation chi tiết, ASN, ISP, Timezone, Cờ bảo mật (VPN, Proxy, Tor, Hosting)

freeipapi.com
- API: https://freeipapi.com/api/json/{IP}
- Free Plan: 60 requests/phút (Miễn phí, không cần API key)
- Dữ liệu: Geolocation, Mã vùng điện thoại, Tiền tệ, Múi giờ, TLD

ripestat (RIPE NCC BGP & Routing)
- API: https://stat.ripe.net/data/prefix-overview/data.json?resource={IP}
- Free Plan: Miễn phí hoàn toàn từ RIPE NCC (Không giới hạn thông thường, không cần key)
- Dữ liệu: Routing BGP, AS announcement, Prefix network chính thức toàn cầu


# ------------------------------------------------------------------------------
# 2. API TRA CỨU TRỰC TIẾP THEO {IP} (TRẢ VỀ JSON - CẦN ĐĂNG KÝ FREE API KEY)
# ------------------------------------------------------------------------------

ipinfo.io
- API: https://ipinfo.io/{IP}/json?token={API_KEY}
- Free Plan: 50,000 requests/tháng miễn phí
- Dữ liệu: Geolocation chuẩn xác cao, ASN, Hostname, Company, Anycast detection

ipgeolocation.io
- API: https://api.ipgeolocation.io/ipgeo?apiKey={API_KEY}&ip={IP}
- Free Plan: 1,000 requests/ngày (~30,000 requests/tháng) miễn phí
- Dữ liệu: Geolocation, ISP, Connection type, Currency, Timezone chi tiết

ipdata.co
- API: https://api.ipdata.co/{IP}?api-key={API_KEY}
- Free Plan: 1,500 requests/ngày (~45,000 requests/tháng) miễn phí
- Dữ liệu: Geolocation, ASN, Carrier, Threat intelligence (Tor, Proxy, Spam score)

abstractapi.com (IP Geolocation)
- API: https://ipgeolocation.abstractapi.com/v1/?api_key={API_KEY}&ip_address={IP}
- Free Plan: 20,000 requests/tháng miễn phí
- Dữ liệu: Geolocation, Security detection, Timezone, Currency

ip2location.io
- API: https://api.ip2location.io/?key={API_KEY}&ip={IP}
- Free Plan: 30,000 requests/tháng miễn phí
- Dữ liệu: Geolocation, ASN, Net speed, Proxy detection
